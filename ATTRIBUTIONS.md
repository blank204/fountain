# Third-party assets & licenses

Every bundled asset must be license-safe for commercial release. Keep this file current
as assets are added.

|---|---|---|---|
| Pixelify Sans (variable) | `app/src/main/res/font/pixelify_sans.ttf` | SIL Open Font License 1.1 | Google Fonts — github.com/google/fonts `ofl/pixelifysans` |
| App icon (pixel fountain) | `app/src/main/res/drawable/ic_launcher_foreground.xml` | Original (self-made) | This project |

## Notes
- **No Toby Fox / Deltarune assets** are shipped. The pixel-pop notification sound (added in a
  later milestone) will be an original synthesized asset, not the real game blip.
- The SIL OFL requires that the font's license accompany the software. The full OFL text is
  bundled with the font upstream; retain a copy alongside the font before release.
